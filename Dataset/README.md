# Dataset 

This dataset is curated for the purpose of building a machine learning model that detects the ripeness level of various fruits and vegetables using image data.

The dataset is organized into folders based on fruit types and ripeness stages, and has been collected from real-world sources, including Edge Impulse captures, ESP-32 cameras, and publicly available datasets.


## Source

- Images collected manually using ESP32 cameras
- Edge Impulse data capture tool
- Public domain agricultural datasets
- Google Images (manually verified and filtered)

## Use Cases

- Computer Vision Model Training
- Ripeness Classification using CNNs
- Real-time inference on embedded devices (e.g., ESP32-CAM)
- Integration with IoT-based agriculture monitoring systems
